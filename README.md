# Primera Persona 3D
Es un projecto de prueba que busca investigar los diferentes aspectos de Unity Engine en entornos 3D con el uso de Stater Assets

### Este Projecto contiene
- Movimiento en primera persona (De Starter Assets)
- Enemigos con Pathfinding a partir de NavMesh
- Projectiles disparables
- Sistema de vida global
- Mapa unico
- Condiciones de victoria y game over
